# Codex Execution Brief

## Роль

Работай как Staff Product Engineer и архитектор образовательных симуляторов.

## Первая задача

Не начинай сразу реализовывать все шесть глав.

Сначала:

1. Проведи архитектурное ревью репозитория.
2. Сопоставь GDD, PRD, UI Bible, Engineering Principles и Technical Architecture.
3. Найди противоречия, пробелы и чрезмерную сложность.
4. Подготовь короткий отчёт.
5. Предложи план реализации вертикального среза Chapter 01.
6. Создай ADR по решениям, которые необходимо принять до разработки.

## После ревью

Реализуй вертикальный срез Chapter 01:

- First Request;
- Hallucination;
- Context;
- Tools;
- Boss;
- Assistant Blueprint;
- первая запись Codex;
- сохранение;
- базовый Dashboard.

## Ограничения

- Не реализовывать Chapters 02–06 до приёмки Chapter 01.
- Не дублировать контент в коде.
- Не добавлять генеративный AI без отдельного ADR.
- Не менять GDD и PRD без явного описания причины.
- Не создавать сложный backend, если потребность не подтверждена.
- Не использовать случайность без seed.
- Не скрывать незавершённые части за моками без маркировки.

## Обязательные результаты первой итерации

- architecture-review.md;
- implementation-plan.md;
- ADR;
- рабочий каркас приложения;
- валидатор контента;
- минимальная модель состояния;
- тесты ключевых правил;
- инструкция запуска;
- список открытых вопросов.
