# Learning Philosophy

1. Сначала проблема, потом теория.
2. Любое понятие должно менять решение.
3. Ошибка должна быть безопасной, но содержательной.
4. Последствия важнее мгновенной оценки.
5. Игрок должен объяснять компромисс.
6. Один экран — одна мыслительная задача.
7. Повторение происходит через новые контексты, а не через одинаковые тесты.
8. Знание считается усвоенным, когда игрок применяет его без прямой подсказки.
