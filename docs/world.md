# Мир AXIOM

AXIOM — AI-платформа, пережившая несколько поколений моделей,
команд и продуктовых стратегий.

Система состоит из множества взаимосвязанных слоёв. Некоторые были
созданы осознанно, другие появились как быстрые решения.

ZERO — интерфейс системы и проводник игрока. Он видит историю решений,
но не обладает абсолютным знанием.

Главный конфликт мира: систему нельзя исправить одной технологией.
Любое улучшение меняет баланс ограничений.
