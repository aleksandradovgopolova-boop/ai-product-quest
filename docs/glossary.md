# Glossary

## AI-продукт
Система, которая создаёт ценность для пользователя с помощью моделей,
данных, интерфейсов, правил, интеграций и процессов эксплуатации.

## Ограничение
Условие, которое влияет на допустимые решения: бюджет, безопасность,
задержка, качество, инфраструктура, регулирование или доступность данных.

## Обратимость
Возможность отменить решение без критического ущерба.

## Эффект второго порядка
Последствие, возникающее не сразу и часто за пределами исходного компонента.

## Артефакт
Инженерный документ, созданный на основе решений игрока.
