# Зона `custom`

Оверлей проекта, который родительский кит не трогает при обновлении: `.ai/managed/**` перезаписывается, `.ai/project/**` и `.ai/custom/**` защищены (`.ai/managed/security/boundary-model.md`).

Что сюда кладут: собственные команды, скиллы и промпты, специфичные для AI Product Quest и не входящие в поставку кита.

Что сюда не кладут:

- знание о продукте, стеке и процессе — это `.ai/project/context/**`;
- контракты событий и метрик — это `.ai/project/contracts/**`;
- что-либо, что должно приходить из кита, — правка `.ai/managed/**` вручную ломает проверку целостности (правило 20 в `REPOSITORY_RULES.md`).

Зона пока пуста: файл нужен, чтобы каталог существовал в git и проходил проверку зон в `npm run ai:validate`.
