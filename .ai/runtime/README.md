# Зона `runtime`

Рабочее состояние прогонов, которое создаёт рантайм во время исполнения: `workitems/<id>/` под конкретную задачу и append-only журнал действий `interaction-log.jsonl`.

Содержимое зоны не версионируется — оно относится к одной машине и одному прогону, а не к проекту. Локальный `.gitignore` рядом исключает всё, кроме себя и этого файла, поэтому каталог существует в git пустым.

Каталог нужен заранее по двум причинам: проверка зон в `npm run ai:validate` требует его наличия, а рантайм рассчитывает на готовый путь и не обязан его создавать.
